# Krajinný kompas

Statická česká aplikace pro rozhodování o krajině. Výsledky musí fungovat ihned bez formulářů; dokumenty jsou nepovinný místní vstup, nové se slučují bez tichého přepisování a export zachovává původ i nejistoty. Vite, vanilla JS, lokální PDF.js a Tesseract. Příkazy npm test a npm run build. Soukromé skutečné parcely nikdy nepatří do repozitáře; výchozí výsledky jsou obecné a neobsahují parcely. Import zpracovávat jen v prohlížeči, ukládání pouze volitelné. Nevydávat kandidátní podporu za potvrzený nárok, rozlišovat neznámé údaje. Voda: tůň, mokřad, tok a rybník mají odlišné důsledky; bez místního posouzení neslibovat vhodnost. Odborné informace musí mít primární zdroje a datum ověření.
