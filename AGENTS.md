# Krajinný kompas

Statická česká aplikace pro rozhodování o krajině. Vite, vanilla JS, Leaflet. Příkazy npm test a npm run build. Soukromé skutečné parcely nikdy nepatří do repozitáře; výchozí portfolio je smyšlené. Import zpracovávat jen v prohlížeči, ukládání pouze volitelné. Nevydávat kandidátní podporu za potvrzený nárok, rozlišovat neznámé údaje. Voda: tůň, mokřad, tok a rybník mají odlišné důsledky; bez místního posouzení neslibovat vhodnost. Odborné informace musí mít primární zdroje a datum ověření.
